# 金铲铲卡池估算器

适用于 Android 8.0 及以上的离线卡池估算工具（非官方）。

## 下载

- [下载 APK 安装包](https://github.com/wangzic59-svg/123/raw/refs/heads/main/downloads/JCC_CardPool_0.1.apk)
- [下载 ZIP 压缩包](https://github.com/wangzic59-svg/123/raw/refs/heads/main/downloads/JCC_CardPool_0.1.zip)

在安卓手机上下载 APK 后，打开文件安装。ZIP 需先解压再安装其中的 APK。使用悬浮窗需要授予“在其他应用上层显示”权限。

这是 0.1 测试版，使用调试签名。已通过编译、计算测试、静态检查（仍有警告）、APK 签名与对齐验证，尚未进行真机测试。概率由手动参数估算，不预测游戏实际结果。
